# Perimeter trees stand upright

Perimeter woodland was painted into the stretched ground image. Its fixed1.5 vertical fudge could not follow viewport changes, a receipt reducing map height, or the detailed sidebar. The live terrain now reuses a shared owned woodland SVG source inline so tree bodies can inherit the measured scene correction. Roots stay fixed on the ground. Ground shadows remain on the flat dirt projection rather than stretching with tree crowns. Shorter edge trees retain their authored species/edge variation.

The original terrain image remains as the background and failure fallback. Once woodland loads, a tree-free bitmap floor covers the static woodland. Roads and low-contrast grain stay in cached images, avoiding a live SVG turbulence filter during play. No new scenery, routes, costs or game rules. The source fetch is cancellable when a map changes or unmounts. Terrain asset URLs and site selection still choose the same four themes. Opening and result illustrations keep their existing static projection.

Tests compare actual screen matrices and root points before/after the monthly receipt, viewport changes and the detailed sidebar. The same checks run against the compiled app; an intercepted fetch failure verifies the original background still decodes and land controls still work. All four real site choices are exercised.
