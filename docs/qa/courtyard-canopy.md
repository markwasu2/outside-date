# Courtyard canopy

The single-hall courtyard trees now have trunks, branches and raised, layered crowns instead of flat green circles. Each casts a ground shadow. The vertical geometry compensates for the wide map camera, so the trees look upright beside the building. The courtyard remains absent in multi-hall campuses.
