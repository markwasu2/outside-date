byte-for-byte identical because bots call step(), not the UI fastForward helper.

The helper now ignores resolved dated milestones and the old invented takeout estimate.

runway, current dated milestones, live covenant trouble, failed inspection, lender freeze
and discovery still stop it. Every skipped month uses ordinary step(). It stops on an
event, newly ready stage or newly energized hall so the next instruction is not lost.

prove a five-month plant wait stops one month before the live online date.
