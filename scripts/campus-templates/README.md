# Full authored campus assets

Full SVG sources in this folder replace the generator's matching asset byte-for-byte. Use these when an authored asset has its own defs, material treatment and complete geometry. Partial additions belong in `scripts/campus-details/` instead.

The dry-field template preserves its soil contours, groundcover and grass tufts. The unit source check requires it to match the game asset exactly. A clean full regeneration must leave every generated asset unchanged.
